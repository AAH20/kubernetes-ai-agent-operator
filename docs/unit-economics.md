# Unit economics and KPIs

Primary metric:

```text
cost per accepted change =
(agent + model + sandbox + storage + network + telemetry + retries + review + operations)
/ independently accepted changes
```

## KPIs

- accepted task rate and accepted PR rate;
- time from submission to reviewed artifact;
- human-review minutes per accepted change;
- duplicate external actions (target: zero);
- unapproved production mutations (target: zero);
- cross-tenant disclosures (target: zero);
- mean sandbox provisioning and recovery time;
- evidence completeness;
- approval-expiry rejection rate;
- warm-pool utilization and idle cost;
- cost per accepted change;
- gross margin per managed tenant.

Example prices are modeling assumptions, not Azure quotations. Capture timestamped retail prices and measured utilization before presenting customer ROI.
